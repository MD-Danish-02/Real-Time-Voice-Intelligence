# Knowledge
PDF/DOCX/TXT upload (10 MB cap, extension allow-list, magic-byte check, sanitised filename, per-tenant dir; ClamAV hook point documented in code), website ingestion (http/https only, DNS-resolved IP must be public, no redirects, 10 s / 2 MB caps, html/plain only), FAQ/product/service/custom text. Pipeline: parse -> clean -> chunk (800/120) -> embed -> pgvector. Default embedder is a real dependency-free hashing embedder (works offline; modest quality); set `KNOWLEDGE_EMBEDDING_MODE=sentence_transformers` for MiniLM. Retrieval: cosine top-k with similarity threshold, always filtered by tenant. Not built: per-document metadata filters in the API, URL crawling beyond a single page.
